El inventario se guarda localmente en este navegador; no se sincroniza con otros celulares ni con una base de datos compartida.

Importante: identificación en tiempo real significa que el modelo clasifica continuamente el producto que ocupa la cámara. Este clasificador no localiza ni cuenta automáticamente muchos objetos en un estante. Para eso se necesita un modelo de detección de objetos y datos anotados con cajas.
